# Cloud Platform Comparison

| Category | AWS | Microsoft Azure | Google Cloud Platform |
|---|---|---|---|
| Launch Year | 2006 | 2010 | 2008 |
| Compute Service | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| Storage Service | Amazon S3 | Azure Blob Storage | Cloud Storage |
| Networking Service | Amazon VPC | Azure Virtual Network | Google Cloud VPC |
| Identity Service | AWS IAM | Microsoft Entra ID | Cloud IAM |

## Questions

### 1. Which cloud provider offers the broadest range of services?

AWS offers a very broad range of cloud services covering computing, storage, networking, databases, security, analytics, artificial intelligence, and other technologies. It is a strong general-purpose cloud platform.

### 2. Which provider best integrates with Microsoft technologies?

Microsoft Azure best integrates with Microsoft technologies. It works particularly well with Windows Server, Microsoft 365, and Microsoft Entra ID.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

Google Cloud is particularly strong in Artificial Intelligence, Machine Learning, and Kubernetes. Google provides Google Kubernetes Engine for managed Kubernetes workloads.

### 4. Which cloud platform would you personally choose and why?

I would personally choose Google Cloud because of its strong capabilities in artificial intelligence, machine learning, data analytics, and Kubernetes. These technologies are useful for modern cloud applications and future projects.

# Equivalent Cloud Services

| Service Category | AWS | Azure | GCP |
|---|---|---|---|
| Virtual Machine | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| Object Storage | Amazon S3 | Azure Blob Storage | Cloud Storage |
| Identity Management | AWS IAM | Microsoft Entra ID | Cloud IAM |
| SQL Database | Amazon RDS | Azure SQL Database | Cloud SQL |
| Kubernetes | Amazon EKS | Azure Kubernetes Service (AKS) | Google Kubernetes Engine (GKE) |

## Service Descriptions

### Virtual Machine

Virtual machine services provide cloud-based servers for running operating systems and applications.

### Object Storage

Object storage services are used to store files and other unstructured data.

### Identity Management

Identity management services control users, authentication, authorization, roles, and permissions.

### SQL Database

Managed SQL database services provide relational databases while reducing infrastructure management requirements.

### Kubernetes

Managed Kubernetes services provide tools for deploying and managing containerized applications using Kubernetes.
