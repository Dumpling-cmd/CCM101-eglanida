# Mission 3 Reflection

The cloud platform that impressed me the most was Google Cloud because of its strong capabilities in Artificial Intelligence, Machine Learning, data analytics, and Kubernetes. During this laboratory, I learned that each cloud provider has different strengths and that the best choice depends on the requirements of a business.

AWS, Azure, and GCP have many similarities. All three platforms provide virtual machines, object storage, networking, databases, identity management, containers, monitoring, and other cloud services. They also provide global infrastructure and scalable resources that allow organizations to adjust their cloud environments based on demand.

Business requirements strongly influence cloud platform selection because organizations have different budgets, technologies, workloads, security requirements, and performance needs. For example, an organization that already uses Windows Server and Microsoft 365 may benefit from Azure because of its Microsoft integration. An AI research company may prefer Google Cloud because of its AI and machine learning capabilities.

Acting as a Cloud Solutions Consultant taught me that choosing a cloud provider is not simply about selecting the most popular platform. I learned to examine the actual needs of a client and match those requirements with appropriate cloud services. This includes considering scalability, availability, existing technology, and the type of workload being hosted.

My GitHub Cloud Computing Portfolio improved after completing this mission because it now contains organized research, comparison tables, client recommendations, a multi-cloud decision matrix, Linux investigation results, screenshots, and a reflection. The laboratory also helped me understand how different cloud platforms provide equivalent services under different names. Overall, this mission improved my ability to compare cloud technologies and make cloud recommendations based on business requirements.
