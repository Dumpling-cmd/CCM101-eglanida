# Laboratory 05 – Cloud Data Engineer

**Name:** Edmund Glanida

**Course and Section:** BSIT 4-L

## Mission Overview

In this laboratory activity, I learned about different types of cloud storage and deployed an S3-compatible object storage server using MinIO and Docker. I also created a storage bucket and uploaded a test file through the MinIO web console.

## Objectives

- Differentiate between Block, File, and Object Storage.
- Deploy an S3-compatible Object Storage server using Docker.
- Access a cloud service through port forwarding.
- Create a storage bucket and upload an object.
- Document cloud storage operations using Markdown.

## Skills Learned

- Understanding cloud storage types
- Using Docker to deploy a cloud service
- Working with MinIO object storage
- Creating and managing storage buckets
- Uploading objects to cloud storage
- Documenting technical procedures using Markdown
