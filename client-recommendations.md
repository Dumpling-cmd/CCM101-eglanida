# Client Recommendations

## Client A – Startup Company

### Recommended Platform

**Amazon Web Services (AWS)**

### Recommendation

AWS is suitable for the startup because it provides a broad range of cloud services that can support a mobile application. The company has a limited budget but expects rapid growth, so scalable cloud infrastructure can allow resources to increase as demand grows. The startup can avoid purchasing physical servers and use cloud resources based on its requirements. AWS also provides many services that can support the application as the company expands.

### Recommended Services

- Amazon EC2
- Amazon S3
- Amazon RDS
- Amazon VPC

---

## Client B – University

### Recommended Platform

**Microsoft Azure**

### Recommendation

Azure is the best choice because the university already uses Windows Server, Microsoft 365, and Active Directory. Azure provides strong integration with Microsoft technologies and supports hybrid cloud environments. This can make it easier for the university to migrate selected services while continuing to use existing Microsoft systems. Azure can also provide identity, networking, computing, and database services.

### Recommended Services

- Azure Virtual Machines
- Microsoft Entra ID
- Azure Virtual Network
- Azure SQL Database

---

## Client C – AI Research Company

### Recommended Platform

**Google Cloud Platform (GCP)**

### Recommendation

Google Cloud is suitable for the AI research company because the company develops Artificial Intelligence and Machine Learning applications. Google Cloud provides services and computing resources that can support AI and ML workloads. Its data and analytics capabilities can also help researchers process large amounts of information. Google Cloud also provides services for containerized applications and scalable computing.

### Recommended Services

- Compute Engine
- Cloud Storage
- Vertex AI
- Google Kubernetes Engine

---

## Client D – Global E-Commerce Company

### Recommended Platform

**Amazon Web Services (AWS)**

### Recommendation

AWS is suitable for the global e-commerce company because it provides global infrastructure and scalable cloud services. The company requires high availability and automatic scaling, so AWS services can distribute workloads and adjust resources according to demand. Multiple Availability Zones can also help improve application availability. AWS provides services for computing, storage, databases, load balancing, and content delivery.

### Recommended Services

- Amazon EC2
- Amazon S3
- Amazon RDS
- Elastic Load Balancing
- Amazon EC2 Auto Scaling
- Amazon CloudFront

# Multi-Cloud Decision Matrix

| Business Requirement | Recommended Platform | Justification |
|---|---|---|
| Startup Company | AWS | AWS provides scalable services and a broad range of cloud capabilities suitable for a growing startup. |
| Enterprise Organization | AWS | AWS provides a large service portfolio and global infrastructure for enterprise workloads. |
| Microsoft Environment | Azure | Azure provides strong integration with Microsoft technologies such as Windows Server and Microsoft 365. |
| AI / Machine Learning | GCP | Google Cloud provides strong artificial intelligence and machine learning capabilities. |
| Kubernetes Deployment | GCP | Google Cloud provides strong Kubernetes capabilities through Google Kubernetes Engine. |
| Global Web Application | AWS | AWS provides global infrastructure and scalable services suitable for applications serving users around the world. |
